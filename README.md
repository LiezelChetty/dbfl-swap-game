# DBFL · Match. Build. Win.

A responsive swipe-to-match engineering game. Swipe neighbouring icons to match three or more, clear tiles and earn cascade bonuses in 60 seconds.

## Vercel
Import this repository. Choose Other for Framework Preset. Leave Build Command unset and use the repository root as the Output Directory.

## Campaign setup
Edit CAMPAIGN in index.html to set the approved prize and Microsoft Forms URL. The prize draw remains labelled as a demo until confirmed. Email entries are collected by Microsoft Forms, not by this game.

## Controls
Swipe on touchscreens, drag with a mouse, or tap two adjacent icons. Keyboard users can focus a tile and use an arrow key to swap it with a neighbour.
